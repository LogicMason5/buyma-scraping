# EC-Buyma 利用マニュアル

最終更新: 2026-08-12

本マニュアルは、**ECサイトから商品情報を収集し、画像・説明文を整え、BUYMAへ出品する**までの具体的な操作手順を説明します。

---

## 1. このアプリでできること

EC-Buyma は次の3段階を、1つの画面（統合コンソール）で実行します。

| タブ | 名称 | 内容 |
|------|------|------|
| **1 収集** | System1 | 会員制ECサイトから商品情報・画像を取得 |
| **2 生成** | System2 | モデル着用画像（`0.png`）と出品用コメントを生成 |
| **3 出品** | System3 | BUYMAの新規出品フォームへ自動入力・公開 |
| **4 設定** | — | アカウント・ログイン・プロンプト設定 |

推奨の流れ:

```text
収集 → 生成 → 出品
```

---

## 2. 動作環境・事前準備

### 2.1 必要なもの

| 項目 | 説明 |
|------|------|
| Windows 10/11 | 本アプリは Windows 向けです |
| Google Chrome | **必須**。収集・出品はインストール済みの Chrome を起動します |
| インターネット接続 | ECサイト / BUYMA /（画像生成時）ChatGPT |
| ECサイト会員アカウント | Julian / Monti / Minetti / Eleonora など |
| BUYMA パーソナルショッパーアカウント | 出品権限があること |
| ChatGPT ログイン（System2） | Cookie 保存済みであること |

### 2.2 アプリの置き場所（exe版）

ビルド済みアプリは次のフォルダです。

```text
dist\EC-Buyma\
  ├─ EC-Buyma.exe      ← これをダブルクリックして起動
  ├─ _internal\        ← Python本体・モジュール（削除しない）
  ├─ secrets\          ← Cookie / セッション
  ├─ workspace\        ← 収集・生成・出品データ
  ├─ logs\
  └─ assets\
```

**重要**

- **`EC-Buyma.exe` だけを他PCへコピーしても動きません。** 必ず `dist\EC-Buyma` フォルダ一式をコピーしてください。
- 他PCに **Pythonのインストールは不要** です（`_internal` に同梱済み）。
- 他PCにも **Google Chrome** が必要です。

### 2.3 開発環境から起動する場合

```powershell
cd C:\development\EC-Buyma
py -3 run.py
```

※ 開発起動時、タスクバーが Python アイコンになることがあります。配布用は `EC-Buyma.exe` を使ってください。

## 3. 初回セットアップ（必ず実施）

初回は **ログイン情報（Cookie）の保存** が必要です。パスワードをアプリが自動入力してログインする方式ではなく、**あなたがブラウザでログイン → Cookieを保存** する方式です。

### 3.1 設定タブでアカウント情報を控える（任意だが推奨）

1. アプリを起動し、**「4 設定」** を開く
2. **ECアカウント**（Email / Password / Minetti用PW）を入力
3. **Buymaアカウント**（Email / Password）を入力
4. **「アカウント設定を保存」** を押す  
   → exe と同じ場所の `.env` に保存されます

※ 実際のログインは次の「テストログイン」で行います。

### 3.2 ECサイトへログインしてセッション保存

1. **「4 設定」** → ECの **テストサイト** を選ぶ  
   - `julian-fashion` / `montiboutique` / `minettiangeloonline` / `eleonorabonucci`
2. **「テストログイン」**（または同等のボタン）を押す  
   - Chromeが開きます
3. サイトに **手動でログイン** する
4. ログイン完了後、コンソール画面に戻り **Enter** を押す
5. 保存先（例）:

```text
secrets\ec_sessions\<サイト名>\storage_state.json
```

**全サイト分**、同様にログイン保存してください（収集で使うサイトのみで可）。

### 3.3 BUYMAへログインしてCookie保存

1. **「4 設定」** で Buyma のテストログインを実行  
   （またはコマンド）

```text
EC-Buyma.exe --buyma-cookie-login
```

2. 開いた Chrome で BUYMA に手動ログイン
3. 完了したらコンソールで **Enter**
4. 保存先:

```text
secrets\buyma_cookies.json
```

### 3.4 ChatGPT Cookie（System2用）

画像生成を使う場合、ChatGPT の Cookie が必要です。

```powershell
py -3 scripts\chatgpt_cookie_login.py
```

保存先:

```text
secrets\chatgpt_cookies.json
```

## 4. 画面の見方

起動すると **「EC-Buyma — Unified Console」** が開きます。

- 上部タブ: `1 収集` / `2 生成` / `3 出品` / `4 設定`
- 下部: ログ（進捗・エラー）と進捗バー
- 「3 出品」タブでは、商品リスト表（✓ / 赤い↻）が表示されます

## 5. 「1 収集」の使い方（System1）

### 5.1 目的

会員制ECサイトから商品を取得し、次を作成します。

- `workspace\scrape\run_YYYYMMDD_HHMMSS\products.csv`
- 商品ごとの画像フォルダ
- ワークブック `workspace\generate\products_workbook.xlsx`（当日シート）

### 5.2 操作手順

1. タブ **「1 収集」** を開く
2. 対象サイトにチェックを入れる  
   - Julian Fashion / Monti Boutique / Minetti Angelo / Eleonora Bonucci
3. **目標件数** を入力（例: `20`）
4. **出力先** は通常そのままでOK  
   - 既定: `workspace\scrape`
5. 実行方式を選ぶ  
   - **手動（収集のみ）**: 収集だけ行う  
   - **自動（完了後 Studio 連鎖）**: 収集完了後、自動で「2 生成」へ進む
6. 必要なら **「新着のみ取得」** にチェック
7. **「開始」** を押す
8. ログで進捗を確認。止めるときは **「停止」**

### 5.3 成功時にできる主なファイル

```text
workspace\scrape\run_XXXXXXXX_XXXXXX\
  ├─ products.csv
  └─ images\
      └─ <ブランド>_<商品>_...\
          ├─ （EC画像）
          ├─ 98.png   ← 在庫確認用共通画像
          └─ 99.png   ← ラッピング用共通画像
```

CSVの主な列: 商品名 / ブランド / カテゴリ / 仕入先URL / 価格 / **在庫** / サイズ / カラー系統 など。

## 6. 「2 生成」の使い方（System2）

### 6.1 目的

- モデル着用の出品用画像 `0.png` を生成（フレーム加工あり）
- CSVの **商品コメント** などを整える
- `workspace\generate\products_ready.csv` などを更新

### 6.2 操作手順

1. タブ **「2 生成」** を開く
2. **入力CSV** に System1 の `products.csv` パスを指定  
   - 「1 収集」を自動連鎖にした場合は、パスが自動入力されることがあります
3. **出力先**（既定 `workspace\generate`）を確認
4. **「開始」**
5. ChatGPT Cookie が切れていると失敗します → 3.4 を再実施

### 6.3 注意

- 生成には時間がかかります（件数×待機）
- 途中停止は **「停止」**
- 在庫数は System1 の値を維持するよう設計されています（空欄時のみ既定値）

## 7. 「3 出品」の使い方（System3）

### 7.1 目的

BUYMAの「新規出品」画面に、CSVの内容を上から順に入力し、確認 → 公開まで行います。

### 7.2 事前確認

- BUYMA Cookie が有効であること（3.3）
- Chrome で BUYMA にログインできること
- 入力CSVに画像フォルダパスが含まれていること（System1/2後のCSV推奨）

### 7.3 操作手順（シートから出品）

1. タブ **「3 出品」** を開く
2. **「シート出品」** を選ぶか、**「手動CSV」** でCSVを指定
3. ワークブックを使う場合:
   - **シート** を選ぶ（例: `2026-08-12 (3)`）
   - **「再読込」** → **「シート→CSV」**  
     → `workspace\generate\sheet_...._export.csv` が作成され、リストに表示されます
4. **「出品確定」**  
   - ON: 実際に公開する  
   - OFF: 入力確認まで（公開しない）※運用に合わせて選択
5. **「開始」**

### 7.4 出品リストの見方

下部の **出品リスト** にCSVの商品が表示されます。

| 表示 | 意味 |
|------|------|
| ・ | 未処理 |
| … | 出品処理中 |
| ✓ | 成功 |
| 赤い **↻** | 失敗（クリックで**その商品だけ**再出品） |

**自動再出品はしません。**  
失敗した商品は、一覧の赤い↻を押して個別に再出品してください。

### 7.5 出品時の入力順（内部動作）

アプリはBUYMA画面の上から下へ、おおむね次の順で入力します。

1. 商品画像（AI画像 → 98 → EC画像 → 99）
2. 商品名 / 商品コメント
3. カテゴリ（3階層）
4. ブランド
5. 色・サイズ / 在庫数量
6. 配送方法
7. 購入期限 / 買付地 / ショップ名 / 発送地
8. 価格 / 関税込み
9. 出品メモ / 買付先メモ（仕入先URL）
10. 「入力内容を確認する」→「注意事項に同意して公開する」
11. 完了後「続けて出品する」で次商品へ

### 7.6 結果ファイル

| ファイル | 内容 |
|----------|------|
| `*_listed.csv` | 全件の結果（`出品結果` / `出品URL` / `出品エラー`） |
| `*_failed.csv` | 失敗行のみ（再出品用の控え） |

成功した行の `出品結果` は `ok` になります。次回開始時、成功済みはスキップされます。

## 8. 推奨の一日の運用例

1. **朝**: 設定で Cookie が生きているか確認（必要なら再ログイン）
2. **収集**: 目標件数を決めて「1 収集」開始（自動連鎖なら生成まで）
3. **生成**: 手動の場合は「2 生成」で `products.csv` を指定
4. **出品**: 「3 出品」で当日シート or `products_ready.csv` を指定して開始
5. **確認**: BUYMAの出品リストで内容を目視確認
6. **失敗分**: 出品リストの赤い↻で個別再出品

## 9. フォルダ構成（データ置き場）

exe と同じ階層（開発時はリポジトリ直下）:

```text
workspace\
  scrape\          ← System1 の収集結果
  generate\        ← System2/3 用CSV・ワークブック
  buyma\           ← 出品関連の出力（あれば）
secrets\
  buyma_cookies.json
  chatgpt_cookies.json
  ec_sessions\...
logs\
```

**Cookie / セッションを誤って削除しないでください。**  
商品履歴やCSVを消しても、`secrets` は残す運用が安全です。

## 10. よくある問題と対処

### 10.1 BUYMAにログインできない

- `secrets\buyma_cookies.json` を作り直す（3.3）
- Chrome プロファイルがロックされていないか確認（Chromeをすべて閉じる）
- 既定プロファイル: `C:\chrome-profiles\buyma-worker`

### 10.2 収集がすぐ終わる / 価格がゲスト表示

- ECセッション切れの可能性 → 3.2 を再実施
- 「新着のみ」で既に取得済みだと件数が減ります

### 10.3 画像生成に失敗する

- ChatGPT Cookie 更新（3.4）
- レート制限時は時間を空けて再実行

### 10.4 出品が途中で失敗する（カテゴリ・サイズなど）

- ログの `出品失敗:` を確認
- 出品リストの赤い↻で**その1件だけ**再試行
- カテゴリ名がBUYMA側表記と一致しているかCSVを確認

### 10.5 在庫がすべて「1」になる

- 古いCSVの可能性があります。**System1を再収集**してください
- System2が在庫を潰さないよう修正済みですが、過去CSVはそのままです

### 10.6 他PCで動かない

確認チェックリスト:

1. `dist\EC-Buyma` **フォルダ一式**をコピーしたか
2. 先方PCに **Chrome** があるか
3. `secrets` が入っているか（または先方で再ログインしたか）
4. `C:\chrome-profiles\...` が使えるか（なければ `.env` でパス変更）
